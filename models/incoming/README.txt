Put 3D models for the game here.

Best format: .glb (binary glTF). .gltf with its files, .fbx and .obj also work.
Name each file after what it is, for example:  apache.glb   sabre.glb   bastion.glb   soldier_medic.glb   rifle.glb

What makes a model easy to use:
- one object per moving part, named plainly: hull, turret, gun, rotor, tail_rotor, prop, wheel_l1 ...
- nose or front pointing along one axis, sitting on the ground at height 0
- real-world size in metres if possible (a rough size is fine; it can be rescaled)
- low polygon count (a few thousand triangles), flat colours or one small texture
- for soldiers: a skeleton ("rigged"), standing in a neutral pose
